# 🏔️ Alpine Ascents

Alpine Ascents is a responsive mountaineering website designed to explore the world of mountains, expeditions, and climbing adventures.

## Features
- Responsive design
- Modern navigation bar
- Mountaineering information
- Expeditions and mountain clubs
- Hazards and safety information
- Image gallery

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Project Purpose
To provide an informative and engaging platform for mountain and mountaineering enthusiasts.

## Author
Developed as a frontend web development project.
